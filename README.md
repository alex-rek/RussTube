# RussTube для Android TV и телефона

RussTube 0.5.4 — поиск и просмотр публичных видео RUTUBE, VK Видео, OK и Дзена. В основе — 0W-Tube. Есть отдельные сборки для Android TV и телефона; телевизионная компоновка адаптирована по вашему проекту [PeerTubeTV](https://github.com/alex-rek/PeerTubeTV).

## Android TV

Сворачиваемое боковое меню: Главная, Популярное, Рекомендации, В эфире, Подписки, Каналы, История, Избранное, Настройки. Поиск находится в верхней панели. Как в PeerTubeTV: часы и логотип справа, белая карточка в фокусе, отдельные строки канала, просмотров и даты, метки длительности и прогресса на обложке. Акцент красный.

- Крестовина — перемещение; OK — просмотр или выбор.
- Влево на первой карточке ряда — открыть боковое меню; вправо — свернуть.
- Удерживать OK или нажать Меню на видео — смотреть, подписаться/отписаться, открыть канал.
- Назад — выйти из активного действия; на ленте открыть боковое меню. Следующее нажатие в течение 2,5 секунд завершает приложение. Двойное нажатие можно отключить в настройках.
- В поиске кнопка «Фильтры качества» открывает исходный расширенный поиск с выбором качества и экономией трафика.
- В плеере: название и данные видео поверх затемнения, кнопки ±10 секунд, повтор, скорость, подписка, избранное и боковая панель качества. Кнопка вверх показывает управление, вниз переводит фокус на шкалу, Меню открывает настройки.
- При воспроизведении или буферизации приложение удерживает экран Android TV включённым; при паузе, ошибке и выходе из плеера удержание снимается.

Раздел «Настройки» выполнен как панель категорий по образцу PeerTubeTV: Общие, Интерфейс, Плеер, Поиск, Сеть, О программе. Выбор категории открывает параметры в выезжающей справа панели; «Назад» закрывает её. В «Сети» можно указать HTTP- или SOCKS5-прокси: адрес, порт и при необходимости логин с паролем. Он применяется к поиску, обложкам, получению ссылок и видеопотокам; UDP-прокси для этих HTTPS-соединений не используется. Для выхода из режима прокси выберите «Без прокси».

## Телефон

Отдельная сборка с мобильной компоновкой в духе YouTube: вертикальная лента с обложками 16:9, поиском сверху, подборками тем и нижним меню «Главная», «В эфире», «Подписки», «Вы». Карточки показывают платформу перед каналом, просмотры, дату и длительность. В разделе «Вы» доступны история, избранное и настройки рекомендаций; список каналов открывается из подписок.

Портретный экран просмотра показывает видео сверху, ниже — название, просмотры, канал, подписку, избранное и выбор скорости/качества. Касание видео показывает кнопки паузы, перемотки на 10 секунд, шкалу и значок полного экрана. Полноэкранный режим скрывает шапку и сведения под роликом без поворота телефона и сохраняет пропорции вертикального видео; повторное нажатие или «Назад» возвращает обычный вид. После окончания видео в полноэкранном режиме приложение возвращает к прежней ленте карточек с сохранением позиции прокрутки. Во время просмотра экран телефона удерживается включённым. При блокировке экрана или сворачивании приложения звук продолжается в фоновом сервисе; уведомление позволяет поставить воспроизведение на паузу, продолжить или остановить. После возврата к плееру видео продолжается с текущей позиции. Для отображения уведомления на Android 13 и новее дайте приложению разрешение на уведомления. Поиск и платформа видео остаются RussTube, авторизация YouTube не используется.

При горизонтальном просмотре видео занимает весь экран; поворот во время воспроизведения сохраняет плеер и позицию. Горизонтальная лента показывает две карточки в строке, а поиск, разделы и сортировка находятся в одной прокручиваемой строке. Поворот не запускает повторный поиск.

## Порядок видео

Над лентой в мобильной версии и в строке действий на Android TV есть кнопка сортировки. По умолчанию показываются сначала новые видео. Можно выбрать сначала старые, по просмотрам или исходный порядок подборки. Видео без даты или числа просмотров остаются в конце соответствующей сортировки. Выбор сохраняется отдельно в каждой версии приложения и применяется к уже загруженным результатам без повторного поиска.

## Рекомендации

На устройстве выделяются темы из последних 30 просмотров. До трёх тем используются для поиска новых видео на четырёх платформах. Результаты ранжируются по совпадению тем и каналов; повторы и уже просмотренные видео исключаются. Журнал целиком никуда не отправляется, но платформы получают поисковые запросы по выделенным темам. Рекомендации можно отключить в настройках. Пока истории нет, доступны кнопки интересов и поиск.

История формируется плеером после минуты просмотра. Алгоритм не использует аккаунты платформ и не обещает качество их персональных рекомендательных систем. TV и мобильная сборки устанавливаются как разные приложения и хранят историю и подписки отдельно.

## Подписки и каналы

Локальные подписки сохраняются между запусками, максимум 100 каналов. Каналы различаются по платформе и стабильному идентификатору, а не по названию. Есть лента видео подписок, список каналов и отписка.

- RUTUBE: идентификатор автора и публичная лента его видео.
- VK Видео: owner_id и публичная выдача video.get; доступ зависит от разрешений анонимной сессии.
- OK: видеоканал/альбом из owner.album. Лента включает только карточки с соответствующим parentEntityId.
- Дзен: publisher из source; поиск по названию с обязательной проверкой идентификатора автора. Это подборка доступных видео автора, а не гарантированная хронологическая лента всех загрузок.

Если платформа не передала идентификатор канала, приложение сообщает об этом и не создаёт подписку по догадке. Подписки не синхронизируются с аккаунтами сайтов.

## В эфире

Раздел ищет трансляции RUTUBE и VK Видео, отбирая только подтверждённые активные эфиры. Название «прямой эфир», нулевая длительность, завершённая запись или анонс не считаются действующей трансляцией. Для VK поиск проверяет несколько страниц, пропуская записи. Доступны темы и свой запрос.

Публичные API могут возвращать пустой результат или не передавать статус эфира. Эфиры OK и Дзена в этой версии не подключены. Полный каталог телеканалов и телепрограмма не реализованы.

## Сборка и установка

Нужны JDK 17 или новее и Android SDK 36. Задайте SDK в локальном `local.properties` (не включён в Git):

```properties
sdk.dir=C\:/Users/alex/AppData/Local/Android/Sdk
```

```powershell
.\gradlew.bat :app:testMobileDebugUnitTest :app:testTvDebugUnitTest :app:lintMobileDebug :app:lintTvDebug :app:assembleMobileDebug :app:assembleTvDebug
adb install -r app/build/outputs/apk/mobile/debug/app-mobile-debug.apk
```

Готовые APK: [RussTube для телефона](https://github.com/alex-rek/RussTube/releases/download/v0.5.4/RussTube-Mobile-0.5.4-debug.apk) (`ru.russtube.tv.mobile`) и [RussTubeTV](https://github.com/alex-rek/RussTube/releases/download/v0.5.4/RussTube-TV-0.5.4-debug.apk) (`ru.russtube.tv`); SHA-256 опубликованы рядом с ними в релизе. Минимальный Android 6.0 (API 23). Подпись отладочная.

Начиная с версии 0.5.2 обе сборки при запуске проверяют публичные релизы этого репозитория, включая предварительные. Когда появится более новая версия с APK для данного устройства, приложение предложит скачать её. После согласия оно сверит SHA-256 и пакет APK, затем откроет системный установщик. Android может попросить разрешить установку из RussTube; окончательное подтверждение установки остаётся за пользователем. При переходе с 0.5.1 версию 0.5.2 нужно установить вручную один раз, поскольку в 0.5.1 проверка обновлений была отключена. Для последующих обновлений требуется та же подпись APK; APK, собранные GitHub Actions с другим отладочным ключом, не подходят для обновления установленной версии.

## Проверка

План функции пропуска вставок для RUTUBE, VK Видео, OK и Дзена — в [SPONSORBLOCK.md](SPONSORBLOCK.md). Для RUTUBE найден независимый проект с отдельным API, но его сервер пока недоступен при проверке; автоматический пропуск в текущей сборке не включён.

Проверки сборки, JVM-тесты и Android lint описаны в `VALIDATION.md`. Воспроизведение и удержание экрана проверены на Android TV и телефонном эмуляторах; для полноценного выпуска ещё нужна проверка на физических устройствах. Публичные интерфейсы платформ могут изменяться; закрытый и защищённый контент может быть недоступен.
