# RussTube 0.6.38

- Необязательный вход в RUTUBE в Mobile и TV через официальный сайт. После входа приложение проверяет профиль; локальные подписки и избранное остаются на устройстве.
- Страница входа RUTUBE использует прокси, выбранный для площадки RUTUBE. Проверка аккаунта проходит через тот же прокси. Для HTTP-прокси поддерживаются логин и пароль.
- Если WebView не поддерживает прокси или соединение не удалось, приложение показывает ошибку и не открывает страницу входа напрямую.

Ограничение: WebView не поддерживает SOCKS5-прокси с логином и паролем. Для страницы входа в этом случае нужен HTTP-прокси или системный прокси. Успешный вход через реальный прокси не проверен; на эмуляторе проверены маршрутизация страницы и запроса профиля через тестовый HTTP-прокси с авторизацией.

APK Mobile и TV подписаны сертификатом предыдущих выпусков. Контрольные суммы SHA-256 приложены.
