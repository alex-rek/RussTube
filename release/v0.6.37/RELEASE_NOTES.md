# RussTube 0.6.37 — локальный выпуск

- В Mobile и TV появился необязательный вход в аккаунт RUTUBE через страницу RUTUBE внутри приложения.
- После входа приложение проверяет профиль; cookie используются только для HTTPS-запросов к API RUTUBE. Выход удаляет локальный веб-сеанс.
- Локальные подписки и избранное RussTube не заменяются данными аккаунта.

На эмуляторе проверены открытие формы входа, проверка анонимного сеанса и навигация пультом. Успешный вход с аккаунтом и воспроизведение в авторизованном сеансе не проверены. Для QR-входа нужен собственный `client_id` RussTube от RUTUBE; текущий выпуск использует вход через сайт.

APK Mobile и TV имеют общий номер версии и подписаны сертификатом предыдущих выпусков. Контрольные суммы SHA-256 приложены.
