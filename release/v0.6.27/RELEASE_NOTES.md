# RussTube 0.6.27

- Mobile: горизонтальный ряд действий под видео, карточка комментариев и список следующих роликов. Первые 20 публичных комментариев RUTUBE и PeerTube открываются в приложении; для других площадок доступен переход на страницу видео.
- Mobile: сохранение доступных прямых файлов MP4 через системный выбор места хранения. Потоковые HLS и DASH пока не поддерживаются для скачивания.
- Mobile и TV: действия «Не рекомендовать канал» и «Просмотрено» в меню видеокарточки. Исключённый канал остаётся в поиске и подписках.
- TV: главная открывается после формирования ленты и подготовки миниатюр первых видимых карточек. Остальные карточки загружаются по мере прокрутки.

Обе APK подписаны тем же сертификатом, что и 0.6.26, для установки поверх предыдущей версии с сохранением данных.
