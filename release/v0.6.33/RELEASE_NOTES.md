# RussTube 0.6.33

## Mobile

- Главная сохраняет порядок карточек на время сеанса и не запускает повторный поиск при каждом возвращении в раздел.
- Если перейти в другой раздел во время загрузки, уже показанные карточки останутся на месте. Новые результаты добавляются после завершения обновления.
- Ошибка одной площадки больше не заставляет Главную повторно пересобираться при каждом входе. Кнопка ручного обновления продолжает загружать свежие видео.

TV пересобран без изменения функций для общего номера версии.

Обе APK собраны в конфигурации release и подписаны сертификатом предыдущих выпусков. Контрольные суммы SHA-256 приложены к выпуску.
