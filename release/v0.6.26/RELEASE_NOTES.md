# RussTube 0.6.26 — оконный режим Mobile

- Верхний правый значок мобильного плеера открывает системное плавающее окно PiP. Кнопка полноэкранного режима остаётся в управлении видео.
- При выключении экрана воспроизведение передаётся существующему фоновому аудиосервису. После включения видео возвращается в окно без одновременной работы двух плееров.
- На устройствах без поддержки PiP показывается понятное сообщение.
- TV получает тот же номер версии без изменений интерфейса и функций.

Обе APK собраны в release-конфигурации и подписаны прежним сертификатом для установки поверх 0.6.25. Отдельный производственный ключ пока не настроен.

Проверки: автоматические тесты Mobile и TV, lint обеих release-сборок, проверка подписи и установка поверх 0.6.25. PiP и передача воспроизведения при выключении экрана проверены в эмуляторе Android. Физические устройства в этом выпуске не проверялись.
