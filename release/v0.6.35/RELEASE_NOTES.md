# RussTube 0.6.35

## TV

- Обычная Главная по умолчанию содержит три ряда: «Рекомендованные», «Новые из подписок» и «По интересам».
- «По интересам» показывает видео по выбранным темам даже без истории просмотра. При новой установке выбраны Новости, Наука и Спорт; темы меняются в настройках Главной.
- Ряды площадок можно включить отдельно в настройках. Они выключены по умолчанию.
- Первые готовые карточки появляются, пока остальные площадки загружаются. Положение рядов сохраняется во время загрузки.

Mobile пересобран с общим номером версии без изменения интерфейса. Обе APK подписаны совместимым сертификатом; контрольные суммы SHA-256 приложены к выпуску.
