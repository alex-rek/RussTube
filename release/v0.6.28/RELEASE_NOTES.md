# RussTube 0.6.28 — исправление зависания TV

- Формирование рядов главной страницы TV выполняется в фоновом потоке. До завершения загрузки показывается экран подготовки; пульт продолжает отвечать.
- Подбор тем по истории ускорен. Просмотренные ролики по-прежнему исключаются из рекомендаций; для определения интересов используются последние 100 просмотров.
- В мобильном плеере «Видео канала» перенесено в горизонтальный ряд действий под видео.
- Изменение затрагивает общий алгоритм рекомендаций Mobile и TV. Остальные функции сохранены.

Сборки подписаны сертификатом предыдущих выпусков и устанавливаются поверх 0.6.27 с сохранением данных.
