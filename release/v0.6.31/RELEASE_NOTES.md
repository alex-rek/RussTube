# RussTube 0.6.31

## RussTube TV

- Главная получила обычный и тематический режимы. В тематическом режиме можно выбрать интересующие темы, а в рекомендациях добавить собственные кнопки.
- При переходе между разделами Главная сразу восстанавливает карточки текущего сеанса. Обновление сохраняет порядок показанных карточек и добавляет новые видео слева.
- Карточки Главной стали крупнее; дата публикации и число просмотров показаны в одной строке.
- Каталог «Фильмы» сохраняется на устройстве на три дня. Кнопка «Обновить» запрашивает свежую подборку.
- Исправлен переход по меню и тематическим кнопкам рекомендаций.

## RussTube Mobile и TV

- В разделе «В эфире → Трансляции» добавлены подборки пользовательских эфиров RUTUBE, VK Live и PeerTube.
- Для обложек VK Live увеличен допустимый размер изображения.

Воспроизведение отдельных эфиров VK Live зависит от доступности платформы и региона: во время проверки на ONN платформа ответила HTTP 403.

APK собраны в конфигурации release и подписаны тем же сертификатом, что и предыдущие версии, чтобы обновление сохранило данные приложения. Контрольные суммы SHA-256 приложены к выпуску.

Существующая линия APK использует сертификат Android debug keystore. Для повышения безопасности подписи потребуется отдельная миграция ключа с сохранением пользовательских данных.
