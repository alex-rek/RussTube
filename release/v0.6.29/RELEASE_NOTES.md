# RussTube 0.6.29 — восстановление воспроизведения

- Mobile и TV: после ошибки загрузки потока во время просмотра обычного видео приложение один раз получает новый адрес и продолжает с текущей позиции.
- Повторное получение адреса ограничено одной попыткой на сеанс, чтобы исключить бесконечный цикл.
- Временный сбой после начала воспроизведения больше не помечает ролик недоступным. Успешный запуск снимает ранее сохранённую отметку недоступности.

Сборки подписаны сертификатом предыдущих выпусков и устанавливаются поверх 0.6.28 с сохранением данных.
