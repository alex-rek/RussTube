# Проверка локальной связи Mobile ↔ TV

Дата: 1 ноября 2026 года. Ветка: `feature/local-sync-audit`.

## Объём

Реализовано сопряжение Mobile и TV в локальной сети, шифрованный обмен, автоматическое аддитивное объединение подписок и избранного, передача видео на TV и базовый пульт телефона. Существующие форматы `subscriptions` и `favorites` не менялись. История, позиции просмотра и плейлисты не синхронизируются согласно уточнению задания.

## Автоматические проверки

- `testMobileDebugUnitTest` и `testTvDebugUnitTest`: пройдены. Тесты покрывают валидацию протокола, очистку ссылок и идентификацию видео.
- `lintMobileDebug` и `lintTvDebug`: пройдены после устранения вызовов API 24 при `minSdk 23`.
- Debug и Release APK обоих вариантов: собраны. Release APK без подписи, так как конфигурация действующего ключа в среде отсутствует. Debug APK подписаны отладочным ключом.

## Проверки на эмуляторах

TV: `emulator-5554`, 1080p. Mobile: `emulator-5556`, API 37. Между эмуляторами использована переадресация ADB-порта, поскольку их виртуальные сети не соединены напрямую.

- Ручное сопряжение: код, сверка отпечатка сертификата, подтверждение на TV — пройдено.
- Передача избранного и подписки с Mobile на TV — пройдена, записи появились в обоих хранилищах.
- Передача нового избранного с TV на Mobile — пройдена.
- Запуск видео VK с телефона на TV: TV самостоятельно получил адрес потока; первый кадр и дальнейшее воспроизведение наблюдались.
- Удалённые Play/Pause и ответное состояние плеера — пройдены.
- QR-сканирование, обнаружение через реальную Wi-Fi/Ethernet сеть, смена IP, восстановление после перезагрузки роутера и три устройства — не проверялись.
- Реальное воспроизведение через локальную передачу для RuTube, OK, Дзен и прямого эфира — не проверялось.

## Ограничения

- Объединение аддитивное: удаления на одном устройстве не передаются и могут появиться снова при следующем обмене. Это следствие сохранения существующих моделей без журнала изменений.
- Без mDNS и при смене адреса/порта может понадобиться повторное ручное подключение.
- Постоянная служба в фоне не запускается; оба приложения должны быть активны.
- Проверка производительности, расхода батареи и поведения на физических устройствах остаётся отдельным этапом.
- Release APK требуют существующий ключ подписи перед установкой как обновления опубликованной версии.
