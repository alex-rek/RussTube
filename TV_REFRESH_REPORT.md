# RussTubeTV — отчёт по обновлению

Ветка: `feature/russtube-tv-2026-refresh`. Основа: `fe74167` (`v0.6.11`). Удалённый релиз не опубликован. Исходное техническое задание: `TZ-RussTubeTV-Codex.md` из папки `RussTube-Codex-TZ`.

## Реализация

- TV-каталог сохраняет разделы и поиск в шапке. Переключатели источников убраны из ленты; сортировка открывает правую панель. Свёрнутая полоса меню, фокус карточек и карточное меню переведены на плоское оформление. В меню карточки есть прежние действия, в том числе «Фильмы» и избранное.
- TV-настройки показывают шесть категорий слева, параметры справа. Для перечислений и мультивыбора используется `SideSelectionPanel`; черновик платформ сохраняется только по «Применить». Добавлены тема, фоновая символика и анимации. Сохранены два независимых масштаба и прежние настройки плеера, сети и обновления.
- Выбор источников общий для обычного поиска и поиска эфиров. Запросы ставятся в очередь только для выбранных площадок; эфиры ограничены RUTUBE, VK Видео и PeerTube. При отсутствии поддерживаемых источников показано пустое состояние. На чистой установке PeerTube выключен для TV и Mobile; явное ранее сохранённое значение не сбрасывается.
- TV-плеер сохраняет часы справа вверху и скрывает логотип. Правые панели объединяют качество, скорость, повтор, отображение, информацию о видео и субтитры. Параметры языка, размера и цвета субтитров открываются вложенными панелями. RUTUBE получает внешнюю SRT/WebVTT-дорожку из `captions[]`; ролик Дзена с метаданными субтитров предпочитает DASH, где есть текстовая дорожка. Существующий путь VK сохранён.
- Из предоставленных файлов установлены мобильные и TV-значки для пяти плотностей, TV-баннер и логотип каталога. Идентификаторы пакетов и формат пользовательских данных не менялись.

## Проверки

Команда Gradle: `testTvDebugUnitTest testMobileDebugUnitTest lintTvDebug lintMobileDebug assembleTvDebug assembleMobileDebug assembleTvRelease assembleMobileRelease --offline`. TV и Mobile: по 119 модульных тестов, 0 ошибок. Android Lint: по 56 предупреждений, 0 ошибок. Проверка `git diff --check` прошла. Эмуляторы: Android TV 1280×720 и Android Mobile; физическое устройство и 1080p/4K не проверялись.

На TV-эмуляторе вручную открыты каталог, настройки, выбор платформ, вложенная панель языка и три контрольных ролика. При тестировании контрольные URL временно добавлялись в избранное эмулятора; исходного файла избранного не было, после проверки тестовый файл удалён. Мобильная сборка показала ленту с обложками и открыла видео в плеере. Сетевые источники могут менять метаданные и доступность роликов независимо от приложения.

## Артефакты и ограничения

- Устанавливаемые тестовые APK: `app/build/outputs/apk/tv/debug/app-tv-debug.apk` и `app/build/outputs/apk/mobile/debug/app-mobile-debug.apk`.
- Release APK: `app/build/outputs/apk/tv/release/app-tv-release-unsigned.apk` и `app/build/outputs/apk/mobile/release/app-mobile-release-unsigned.apk`. Они собраны с R8, но **не подписаны и не устанавливаются как релиз**: переменные существующей подписи `RELEASE_KEYSTORE_PATH`, `RELEASE_STORE_PASSWORD`, `RELEASE_KEY_ALIAS`, `RELEASE_KEY_PASSWORD` не заданы. Новый ключ не создавался.
- AAB проектом не настроены и не собирались. Релиз в GitHub/Google Play не отправлялся.
- Для закрытия A18–A22 нужен отдельный прогон на реальном TV и смартфоне, включая звук, перемотку, смену качества, масштабирование, системный размер шрифта и работу после обновления ранее установленного APK. Для OK/PeerTube сначала нужны публичные ролики с подтверждёнными дорожками.
