# Проверка RussTube 0.5.1

Дата: 22 октября 2026 года.

## Автоматические проверки

Команда: `./gradlew :app:testMobileDebugUnitTest :app:testTvDebugUnitTest :app:lintMobileDebug :app:lintTvDebug :app:assembleMobileDebug :app:assembleTvDebug --no-daemon`.

- По 89 JVM-тестов для мобильной и TV-сборок, ошибок и провалов нет.
- Android lint: 0 ошибок, 29 предупреждений для каждой сборки (включая замечания по accessibility, локализации и drawable).
- Оба отладочных APK собраны.
- Добавленные проверки: исключение просмотренных видео, дедупликация рекомендаций, ранжирование по темам, отсутствие запросов при пустой истории, сохранение метаданных канала при смене качества/длительности, совместимость старых данных, различение одинаковых ID платформ, исключение анонсов и завершённых эфиров, форматы издателя Дзена и видеоканалов OK.
- Парсер ленты OK дополнительно проверен на загруженной публичной странице реального видеоканала: 24 карточки, превью присутствуют, чужие идентификаторы канала не включаются.

## Android TV

Эмулятор Television_720p, Android TV API 36, экран 1280×720.

Проверено: запуск через TV activity, открытие сворачиваемого меню с пульта, переход в поиск, запрос NASA, 27 реальных результатов, превью, фокус карточек, открытие бокового меню кнопкой Menu, сохранение подписки Дзена в SharedPreferences, переход к каналу, 12 результатов с совпадающим publisher ID. Снимки экранов находятся в `screenshots/`.

История из новой установки пуста: проверен текст пустого состояния рекомендаций. Ранжирование и исключение просмотренного проверены JVM-тестами; полноценный цикл накопления истории на физическом телевизоре ещё не проверен.

## Ограничения сетевой проверки

Публичный поисковый endpoint RUTUBE в этой среде отвечал успешно, но возвращал 0 результатов, в том числе по запросам NASA и «прямой эфир». Поиск VK, OK и Дзена возвращал реальные видео. В выборках эфиров VK обнаружены записи со статусом postlive; они намеренно не включаются в активные эфиры. Итоговая проверка раздела «В эфире» на эмуляторе нашла 1 действующую трансляцию VK Видео и показала её с меткой эфира. Воспроизведение этой трансляции на физическом телевизоре не проверялось.

Подписки RUTUBE и VK требуют проверки на устройстве и в регионе, где соответствующие публичные API возвращают данные. В Дзенe подборка канала строится поиском с проверкой publisher ID, поэтому не гарантирует все свежие загрузки.

Аппаратное декодирование, поведение конкретного пульта и длительное воспроизведение на физическом Android TV не проверялись. Полный каталог эфиров OK и Дзена отсутствует.

## Изменение 0.4.1

Мобильный плеер передаёт звук и позицию в foreground service при блокировке экрана и сворачивании приложения. Уведомление управляет паузой, продолжением и остановкой. Возврат к видео восстанавливает текущую позицию и состояние паузы. Сервис использует сетевую блокировку сна для устойчивого воспроизведения при погашенном экране.


Проверено на Android Phone API 37: после выключения экрана mWakefulness=Asleep, сервис AudioPlaybackService оставался foreground, а сохранённая позиция видео выросла с 33 до 59 секунд. Уведомление присутствовало в Notification Manager; после возврата к плееру видео продолжилось с 2:29. Длительное воспроизведение на физическом телефоне и нажатия кнопок уведомления не проверены.

Финальная команда тестов, lint и сборки для Mobile и TV прошла без ошибок.

## Изменение 0.5.0

Мобильный плеер и лента обрабатывают поворот без пересоздания экранов. На телефонном эмуляторе воспроизведение видео Дзена продолжилось при повороте в горизонтальное положение и обратно: позиция выросла с 50 886 до 65 968 мс, ошибка «Очистите кэш» не появилась. Горизонтальный плеер отображался на весь экран; в ленте остались 60 результатов и появились две карточки в строке и компактная прокручиваемая строка управления.

В финальных APK проверены названия RussTubeTV/RussTube. На TV-эмуляторе проверены панель настроек, открытие бокового меню по Back и выход по второму Back. В настройках сети сохранён тестовый HTTP-прокси 127.0.0.1:9: повторный поиск NASA сообщил о недоступности всех четырёх платформ, что подтвердило маршрутизацию запросов через прокси. Затем режим «Без прокси» сохранён, и повторный поиск вернул 27 видео. Для Media3 добавлен отдельный HTTP reader с явной передачей прокси для плейлистов и сегментов. Воспроизведение через реальный прокси и авторизация прокси на физическом устройстве не проверялись.

Финальная команда тестов, Android lint и сборки обеих flavor прошла успешно; lint — 0 ошибок и 33 предупреждения на вариант. Проверка на физических телефоне и телевизоре ещё требуется.

## Изменение 0.5.1

Параметры всех категорий RussTubeTV перенесены из диалогов и отдельного сетевого экрана в выезжающую справа панель настроек. Финальная команда тестов, lint и сборки обеих flavor прошла успешно; lint — 0 ошибок и 35 предупреждений на вариант.

Дополнение по SponsorBlock for Rutube: найден пользовательский скрипт с отдельным API отметок RUTUBE. Его код и формат запроса изучены; указанный домен сервера не разрешился в DNS при проверке 22 октября 2026 года, поэтому чтение реальных отметок и воспроизведение с ними не проверялись.
